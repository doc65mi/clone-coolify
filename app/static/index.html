COME FUNZIONA

Dal piano alla copia.

  1. VerificaIdentità, versioni, risorse e destinazione vuota.
  2. Proteggi i datiFermo applicazioni e backup cifrati con verifica di integrità.
  3. Ricrea e ripristinaNuove risorse, variabili e dati sulla destinazione.
  4. Controlla il risultatoSorgente riavviata. Destinazione ferma per la verifica finale.
Il piano è valido per 15 minuti.

CONNECTION SETUP

Due istanze. Un collegamento.

I token restano sul backend, cifrati. Le chiavi private si montano come file in sola lettura.

Prima di collegare i server

Usa token con visibilità completa sulle risorse: lettura e dati sensibili sulla sorgente, anche scrittura e deploy sulla destinazione. Nella cartella ssh/ inserisci le chiavi e il file known_hosts, dopo aver verificato le impronte SSH. Non usare il clone su uno dei workload da fermare.

Per modificare le connessioni, reinserisci entrambi i token.
